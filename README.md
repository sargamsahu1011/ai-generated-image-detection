# AI Image Detector

AI-generated image detection project using spatial-domain and frequency-domain analysis.

## Project Structure

- branch_a - Spatial-domain detection
- branch_b - Frequency-domain detection
- fusion - Fusion of spatial and frequency predictions/features
- backend - Flask API
- frontend - Web frontend for deployment
- configs - Configuration files
- notebooks - Research and experimentation notebooks
- results - Evaluation results
- checkpoints - Model checkpoints

## Evaluation

The project uses Leave-One-Generator-Out (LOGO) evaluation across multiple image generators.

## Branch A

Spatial-domain image detection using ResNet50.

## Branch B

Frequency-domain image detection.

## Fusion

Combines Branch A and Branch B for final prediction.

## Deployment

Backend: Flask

Frontend: Vercel
